# 毫米波雷达 Yaw 角标定计算器（mmwave-yaw-calib）

一个纯静态网页工具：基于成对二维点（x,y），求解毫米波雷达坐标系到激光雷达坐标系的二维外参（Yaw + 平移），并提供 2D/3D 可视化与拟合误差指标，用于快速核验坐标系定义与标定结果可靠性。

## 在线访问（GitHub Pages）

启用 Pages 后，访问地址为：

- https://a123222.github.io/mmwave-yaw-calib/

如果你刚开启 Pages，可能需要等待数十秒到数分钟生效。

## 功能

- 解析输入点对（Lidar 与 Radar），计算最优 yaw 与平移
- 输出拟合指标：RMSE 与最大误差
- 2D 画布：展示 Lidar 点、Radar 原始点、Radar 变换到 Lidar 后的点
- 3D 坐标系：展示统一右手系 XYZ、Lidar/Radar 坐标系位置关系，支持旋转/平移/缩放交互

## 输入格式

两侧文本框分别输入二维点，一行一个点：

```
x, y
```

要求：

- 两侧点数必须一致
- 点的顺序必须一一对应（第 i 行与第 i 行是同一目标/特征点）
- 单位必须一致（例如都用米）
- 建议点对数量 ≥ 3，且点分布尽量拉开（不要都挤在一小块区域）

## 坐标系与输出含义

本工具求解的是将毫米波雷达点变换到激光雷达点的刚体变换：

```
p_lidar = R(yaw) · p_radar + t
```

- 采用右手系：Z 轴朝上，Yaw 表示绕 Z 轴旋转
- yaw 正值：从 +Z 方向看向原点时逆时针为正

说明：

- “毫米波雷达坐标”应填毫米波雷达自身坐标系下的测量值
- “激光雷达坐标”应填激光雷达自身坐标系下的测量值
- 若你在“激光雷达坐标”里填的是另一个参考系（例如车体/地图系）下的坐标，那么输出将变为 Radar→该参考系的外参（结果会变化，这是正常的）

## 计算原理（二维 Kabsch / Procrustes 解析解）

给定 N 对对应点：

- 激光雷达点：`p_{l,i} = (x_{l,i}, y_{l,i})`
- 毫米波雷达点：`p_{r,i} = (x_{r,i}, y_{r,i})`

目标：最小化

```
min_{R,t} Σ || p_{l,i} - (R p_{r,i} + t) ||^2
```

步骤：

1) 质心：

```
c_l = (1/N) Σ p_{l,i}
c_r = (1/N) Σ p_{r,i}
```

2) 去中心化：

```
q_{l,i} = p_{l,i} - c_l
q_{r,i} = p_{r,i} - c_r
```

3) 二维解析量：

```
a = Σ (x_{r,i} x_{l,i} + y_{r,i} y_{l,i})
b = Σ (x_{r,i} y_{l,i} - y_{r,i} x_{l,i})
yaw = atan2(b, a)
```

4) 旋转矩阵（绕 Z 轴）：

```
R(yaw) = [[cos(yaw), -sin(yaw)],
          [sin(yaw),  cos(yaw)]]
```

5) 平移：

```
t = c_l - R(yaw) c_r
```

拟合质量：

```
e_i = || (R p_{r,i} + t) - p_{l,i} ||
RMSE = sqrt((1/N) Σ e_i^2)
maxErr = max(e_i)
```

## 常见问题与注意事项

- RMSE/最大误差明显偏大：通常是点序不对应、存在外点、坐标轴方向/单位不一致
- 提示“几何退化”：点过于重合或基线过短，导致 yaw 不可稳定辨识；请增加点数并拉开分布
- 本工具为二维 yaw 标定：默认 z=0，不包含 pitch/roll
