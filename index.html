项目简介

本页面用于计算毫米波雷达相对于激光雷达的二维外参（Yaw + 平移）。核心输出为将毫米波雷达点集对齐到激光雷达点集的刚体变换：
p_lidar = R(yaw) · p_radar + t

输入数据要求

  • 两侧文本框分别输入成对的二维点：x, y，一行一个点。
  • 两侧点的顺序必须一一对应：第 i 行激光点与第 i 行毫米波点表示同一个目标/角点/特征。
  • 单位必须一致（例如都用米）。
  • 点对数量建议 ≥ 3，且分布尽量“拉开”（不要都挤在同一小块区域），否则 yaw 不稳定。

坐标系与方向约定

  • 统一使用右手系：Z 轴朝上，Yaw 表示绕 Z 轴的旋转。
  • 可视化中：原点处三轴为 Lidar（激光雷达）坐标系；平移+Yaw 后的三轴为 Radar（毫米波雷达）坐标系。
  • Yaw 正值表示：Radar 坐标系按逆时针方向旋转后更接近 Lidar（以右手系从 +Z 方向看向原点的逆时针为正）。
是否能“在激光雷达坐标系中填写实际测得的坐标”？可以，只要这些点确实是在激光雷达自身坐标系下测得，并且与毫米波侧点对一一对应、同一单位；计算结果就是 Radar→Lidar 的外参，不会因为“是否做了平移”而失真。 但如果你把激光点换成了另一个坐标系（例如车体坐标系/地图坐标系/已经旋转过的坐标），那输出的 yaw 就会跟着改变——因为参考坐标系变了。

计算原理（二维 Kabsch / Procrustes 解析解）

  • 目标：找到旋转和平移，使毫米波雷达点对齐到激光雷达点：p_l = R(yaw) · p_r + t。
  • 计算质心：c_l = (1/N) Σ p_l，c_r = (1/N) Σ p_r。
  • 去中心化：q_l = p_l - c_l，q_r = p_r - c_r。
  • 构造两个标量（互相关的二维解析形式）：a = Σ (x_r x_l + y_r y_l)，b = Σ (x_r y_l - y_r x_l)。
  • Yaw 解析解：yaw = atan2(b, a)。
  • 平移解：t = c_l - R(yaw) · c_r。
旋转矩阵（绕 Z 轴）：R(yaw) = [[cos(yaw), -sin(yaw)], [sin(yaw), cos(yaw)]]
误差评估：对每个点计算 e_i = || (R · p_{r,i} + t) - p_{l,i} ||； RMSE = sqrt( (1/N) Σ e_i^2 )，最大误差 max(e_i)。

结果解读与可靠性判断

  • 拟合 RMSE：越小表示点对整体更一致；明显偏大通常是点序不对应、外点较多、坐标系轴方向/单位不一致。
  • 最大误差：能快速发现单个外点或某一对点匹配错误。
  • 若提示“几何退化”，表示点分布信息量不足（点过于重合/基线过短），需要增加点数并拉开分布。

常见注意事项

  • 本工具求解的是二维 yaw：默认所有点位于同一平面（z = 0），不包含 pitch/roll。
  • 请确保两传感器数据来自同一场景/同一时刻，且目标点选取一致。
  • 若发现 yaw 方向“反了”，优先检查：某一套坐标是否存在轴翻转（例如 y 轴方向相反，左手系/右手系混用）。
